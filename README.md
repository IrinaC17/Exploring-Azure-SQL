# ☁️ Azure Data Fundamentals Project

## 📖 Overview

This repository showcases the Azure Data Fundamentals and Cloud Computing projects I completed during my **Level 3 Data Technician Skills Bootcamp with Leep Talent**.

Throughout this project, I developed an understanding of cloud computing concepts, Azure services, data storage solutions, cloud architectures, security and compliance considerations, and Azure data analytics tools. I also completed practical Azure labs using Microsoft Azure's learning environment to gain hands-on experience with cloud-based data solutions.

---

## 🎯 Project Objectives

- Understand cloud computing principles and deployment models
- Explore Microsoft Azure services and data solutions
- Learn cloud service models (IaaS, PaaS, SaaS)
- Compare public, private, hybrid, and community cloud environments
- Investigate cloud pricing and cost management
- Explore data governance, security, and compliance requirements
- Gain practical experience using Azure data services
- Understand modern data analytics and storage solutions in Azure
